## Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| `data` | Datasets limpios en CSV, consumidos por Power BI via URL raw |
| `notebooks` | Scripts de extraccion y limpieza |
| `pbix` | Archivos fuente de Power BI |
| `proyectos` | Una pagina HTML por proyecto |

## Notas

Todos los datos utilizados son de acceso publico. Ningun dashboard contiene informacion de empresas o clientes.
